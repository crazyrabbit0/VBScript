# Contributing

Thanks for helping out. Bug reports and ideas go in [issues](https://github.com/crazyrabbit0/VBScript/issues/new/choose); fixes and new scripts go in pull requests.

## Pull requests

1. Keep each pull request to one script or one change.
2. Read the target from `WScript.Arguments(0)` and quote it so paths with spaces work.
3. Test the script by hand on Windows with a path that contains spaces.
4. Update the table in the [README](README.md) when you add or remove a script or change what one does.
5. Describe how you tested it, including your Windows version.

These are personal VBScript launchers that change real systems, so explain anything that edits the registry, services, files or permissions.
